# NEED-CONNECT — задачи, ожидающие действий владельца

> Файл «дальнего ящика»: задачи, которые нельзя выполнить без твоих действий
> (ключи, домены, сервисы, материалы). Как только условие выполнено — скажи,
> и задача переносится в работу.

## 1. Email-сервис для писем с домена
- **Что блокирует:** подтверждение email (окна готовы), восстановление пароля,
  уведомления о привязке.
- **Нужно:** выбрать сервис и добавить ключи в Vercel. Варианты:
  - **Resend** (рекомендую): 3000 писем/мес бесплатно, домен vercel-дружелюбный,
    отправка через API — нужен `RESEND_API_KEY` + подтверждение домена (SPF/DKIM).
  - Brevo: 300 писем/день бесплатно.
  - SMTP твоего хостинга (если у revoluttime.de есть почта).
- **Мой шаг после ключей:** привязка + подтверждение + восстановление (E3 из плана).

## 2. Домен revoluttime.de
- **Нужно:** подключить домен к Vercel (Settings → Domains) и запустить
  `TELEGRAM_BOT_TOKEN=<токен> SITE_URL=https://revoluttime.de node scripts/ultra/setup-tg-webhook.mjs`,
  чтобы бот слал ссылки входа с нового адреса.
- После переезда: `NEXT_PUBLIC_SITE_URL=https://revoluttime.de` в Vercel + Redeploy.

## 3. Facebook-вход
- `FACEBOOK_APP_ID/SECRET` сейчас лежат в СТАРОМ проекте `revoluttime` — перенести
  в проект `revolut-time` (или прислать значения — добавлю сам).
- Facebook требует подтверждения бизнеса — без него OAuth-диалог не пускает
  обычных пользователей. Кнопки на сайте остаются disabled.

## 4. PDF-отчёт Eurofins и сканы сертификатов
- **Нужно:** прислать PDF отчёта Eurofins (AR-26-HH-013581-02) и сканы
  сертификатов — повешу их на страницу /certificates.

## 5. Задняя сторона этикетки
